# Artificial PsyArch Test Experiments and Paper Data Appendix

本仓库是《人工心智架构（Artificial PsyArch）》论文的实验数据与复现附件。它只收录正文采用的强证据实验材料，开发期短扫、早期失败批次和参数搜索结果不进入主索引；这些材料如需追溯，可回到原始本地 artifact 目录查看。

## 内容概览

- `experiments/E01` 至 `experiments/E17`：每个实验的设计说明、终稿报告、终稿汇总表、逐项数据表、白箱日志摘要、论文图表和最小数据集。
- `paper_quality_charts_v02`：论文正文使用的总览图和分域图，只由终稿强证据数据生成。
- `scripts`：复现实验与重新生成论文图表所需的脚本副本。
- `MANIFEST.md` 与 `manifest.json`：附件文件索引、源文件映射、哈希和样本规模。
- `REPRODUCE.md`：从 AP 原型仓库运行实验、重新生成表格和图表的步骤。

当前强证据总览覆盖 E01-E17，共 914 条判定记录。E01 是小样本强因果控制实验，正文使用时按“严格交叉 probe 机制证据”理解；E02-E17 则提供更大规模的对照、消融或白箱机制记录。

## 证据准入标准

正文证据必须同时满足四项条件：第一，实验目标能被拆成明确的最小机制命题；第二，数据集只改变关键变量，其他条件尽量保持可比；第三，实验调用 AP 原型真实模块或与论文声明一致的白箱机制实现；第四，结果具有方向一致的对照差异，并保留可复查的表格、图表和脚本。

## AP 原型来源

本附件不直接复制完整 AP 原型仓库，因为本地原型包含大量运行日志和数据库文件，直接复制会使附件膨胀到 GB 级。复现时请将 AP 原型仓库放在本仓库同级目录，目录名为 `Artificial-PsyArch`。

记录到的 AP 原型提交：`f1a54e84bc2b9575fc41a3e00c5addc5a639c0bf`

原型工作树在生成本附件时存在本地未提交修改，具体状态见 `ap_prototype_status.txt`。复现者应优先使用随论文发布的 AP 原型仓库版本；若需要完全复核作者本地状态，可对照该状态文件与后续发布的补丁说明。
