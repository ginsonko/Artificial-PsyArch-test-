Public reproduction policy
--------------------------

This attachment package is designed to be used with the public AP prototype
repository released alongside the paper. For the full E01-E17 reproduction
path, apply the minimal reproduction delta above to the recorded base commit.
Keep the prototype repository as a sibling directory named `Artificial-PsyArch`,
or set the `AP_ROOT` environment variable before running the scripts under
`scripts/`.

The delta contains only the prototype paths confirmed by the reproduction audit:
AgentRuntime prompt-packet projection, time-interval closure, residual-memory
time-like promotion, StatePool snapshot explainability, and experiment metrics.
It intentionally excludes local run outputs, frontend build artifacts, PA/NapCat
helper scripts, and unrelated dirty worktree files.

The experiment attachments in this repository contain the data files, summary
tables, charts, script copies, and SHA-256 hashes used by the paper. The root
`manifest.json` records portable logical source identifiers:

- `ap-paper-artifacts://...` identifies the original paper experiment output
  branch used when assembling the public attachment package.
- `ap-prototype://...` identifies a path relative to the AP prototype
  repository.

These logical identifiers are provided for provenance. They do not require the
reader to reproduce the author's local directory layout.

Integrity check
---------------

Use `manifest.json` to verify the published attachment files. The `bytes` and
`sha256` fields are computed over the files included in this repository.
